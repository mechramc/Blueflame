# Blueflame Agent Guide

This repo is designed for collaborative work with Codex and Claude.

**Source of Truth**
- `Blueflame-Spec-v3-ACAR.md` for the full technical spec.
- `Blueflame-PRD.md` for system breakdown and acceptance criteria.
- `tasks.yaml` for canonical task planning.
- `tasks-readable.md` for human-readable sprint status.

**How to Work**
- Pick a single task from `tasks.yaml` and scope your change set to that task.
- Keep diffs small and verifiable.
- Update `docs/STATUS.md` with current focus and decisions.
- Add or update docs in `docs/` when behavior changes.

**Project Goals**
- Spec-first SDLC with governed agent execution.
- Azure-first deployment, GitHub-based DevOps.
- Strong auditability, safety, and cost governance.
